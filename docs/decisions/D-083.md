## Decision record

Date: 2026-09-19.

Status: accepted.

Decision: Reconcile the active navigation contract already reflected by current implementation and Product Vision. The row-two work controls are Clinical, Calendar, Team, and Practice. Calendar is a direct first-class workspace. Workspace/layout customization, saved layouts, presets, and related configuration live under Preferences/Settings rather than as a peer work destination. Legacy internal `schedule` and retired workspace/sidebar event identifiers may remain where needed for compatibility, but visible current product language must not present Schedule or Workspace as peer top-level destinations.

Reason: D-070 intentionally removed the launcher/left sidebar but still described an intermediate row containing Schedule and Workspace. D-072 then made Calendar a first-class direct workspace, and current `ToolNavigation` implements Clinical, Calendar, Team, and Practice while Product Vision VIS-03/LAYOUT-06 places layout configuration under Preferences. This ADR records the already-implemented/current product truth so agents do not reconstruct the intermediate shell from historical wording.

Constraints: This is documentation of the current shell contract, not a new navigation rewrite. It does not change clinical authority, patient workspace identity, appointment truth, saved-layout persistence, or compatibility handling for legacy internal IDs. Historical D-070/D-072 rationale remains preserved; D-070 is active but amended by D-072 and this decision.
