# D-123 — History controls fit their surface and action dialogs identify their patient

Decision ID: D-123
Date: 2026-10-04
Status: Accepted
Amends: [D-116](D-116.md), [D-120](D-120.md)

## Decision

TOOL-FIT-1 fulfills the owner-accepted compact History layout slice using intrinsic sizing and wrapping in the existing CSS/token system. The History title, search, Record Vitals and Administer Scale remain in the header. Longitudinal Timeline, Structured Psychiatric History and Clinical Rating Scales remain labeled views beneath it. Timeline stream filters, interval synthesis and event actions retain their current owners and locations. Search receives an accessible name. No control is replaced by an unlabeled icon or a new navigation path, and no font size is reduced.

History's minimum-width dock, expanded canvas and narrow/enlarged single surface use the same mounted component. Fit changes preserve its search, selected stream/view and patient binding. Clinical snapshot retrieval, empty/error/retry states, synthesis behavior and insertion boundary remain unchanged.

The action review discovered that Vitals and Assessments dialogs covered the chart without displaying patient identity. Both shared dialogs now receive the existing bound patient object (only ID/name/DOB/MRN are required), derive their API patient ID from that same object, and display name/DOB/MRN in their header. History, Overview and Labs pass the patient they already own. This prevents independently supplied display identity and request ID from drifting; it does not grant access or change clinical writes.

## Limits

This improves presentation, accessibility, patient identity visibility and validation. It does not improve clinical reasoning, persistence, permissions, external transport or AI capability. The scripted interval synthesis remains the existing demonstration behavior, not a newly implemented model. No new store, router, registry, model, dependency or paid service is introduced.

Shared History CSS and modal call sites remain coupled and require regression coverage. Existing modal form/draft, async and dismissal lifecycles remain unchanged. Cross-browser, detached-window completeness, full browser acceptance and the synthetic clinic-day gate remain separate from this bounded layout result.
