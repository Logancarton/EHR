# Clinical Bond ADR Records

Each file in this directory preserves one stable D-number and its historical rationale.

The current discovery surface is [`../DECISIONS.md`](../DECISIONS.md). That index owns authority status and topic discovery; these files own the detailed rationale.

ADR metadata separates:
- architectural status (Active / Active — amended / Superseded / Deferred or Proposed);
- implementation status;
- amendment/supersession relationships;
- related decisions.

Do not renumber decisions. Do not rewrite old rationale to make it sound current. Add amendment metadata and a later ADR when direction changes.
