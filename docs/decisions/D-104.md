# D-104 — A new note assumes no findings, and safety is grounded in what the clinician wrote

Decision ID: D-104
Date: 2026-09-25
Architectural status: Active / Accepted

Amends: [D-100](./D-100.md) (visit readiness gains a safety part and a new safety rule), [D-101](./D-101.md) (drafts no longer default to a billing level)
Amended by: —
Supersedes: —

## Context

A review of the running app on 2026-09-25 found that every new encounter note opened with a complete *normal* mental status exam. It included "No evidence of delusions, hallucinations, suicidal ideation, or homicidal ideation" and a mood quotation attributed to the patient. Autosave stored it as if a clinician had written it. The note's safety goal was inferred from words such as "denies" or "suicid" in that text, so the readiness panel reported **Safety & Suicidality Assessed — done** on a note whose Risk Assessment was empty. Maya Chen's Overview showed a positive PHQ-9 item-9 alert at the same time. Signing without editing would have put "no suicidal ideation" into the legal record. Nobody had assessed it.

This is the D-102 rating-scale failure (answers pre-filled and counted as complete) in the note itself. It violates the AI and clinical-safety rule that the product never invents patient facts.

The same review found related defects:

- The Overview listed every flag any assessment had ever raised as an "unresolved" safety alert. Maya's March item-9 flag had been superseded by two negative PHQ-9s.
- The chief complaint was pre-filled from a template sentence or from a scripted demo scenario.
- Drafts defaulted to CPT 99214 at the repository, and a readiness item promised "Satisfies Moderate Risk pillar for 99214".
- The first reference read for a new draft returned 404 before the draft reached the server, and the panel reported that as "Linked records could not be refreshed".

## Decision

1. **A new note starts blank.** `defaultMse` is empty in every dimension, and the chief complaint starts empty. A normal exam is one explicit click away: the MSE section's **Insert normal exam** button (or **Fill N blank as normal**). It fills only blank rows, contains no quotation attributed to the patient, and never overwrites a written finding. The template's **Apply template defaults** action still inserts its chief complaint on request.
2. **Old unauthored defaults are removed from drafts.** A dimension of an *unsigned* draft whose text is still byte-identical to the old default is cleared when the draft is loaded. Migration `2026-09-25-003` clears those values at the source with a `clear-unauthored-default` provenance event. Signed notes are never rewritten.
3. **Safety is met by a written Risk Assessment.** Thought-content keywords no longer count. The goal's evidence is `clinician-authored`.
4. **Current safety flags come from the latest administration of each instrument** (`currentSafetyFlags`). The Overview and the note use this same rule. Superseded flags remain on the assessment timeline.
5. **A current flag leads the note.** The readiness server view gains a `safety` part. Each current flag becomes the first Note item and replaces the plain safety goal. It stays open until the Risk Assessment is written, and **Go to Risk Assessment** moves the cursor there. If safety history cannot be read, the panel says so and never reads as "no concern".
6. **No billing level is assumed.** A draft's CPT and E/M level default to empty; the client always sends the coding engine's current derivation. Template badges read "Usually 99214 · MDM decides", and the readiness item says "Counts toward moderate-risk medical decision making".
7. **A draft the server has not yet received is not a failed read.** A 404 from the reference read is "not yet applicable", and the read re-runs when the first save is acknowledged.

## Consequences

- A note shows its real gaps from the first second: MSE, safety, and chief complaint are open until written or explicitly inserted.
- A clinician who wants a normal exam spends one click, and the note records what they chose.
- Seed and demo candidate actions (proposals that need acceptance) still load from the ambient scenario; only facts in the note body stopped being pre-filled.
- An existing draft's chief complaint that came from the demo scenario is not cleared, because it cannot be told apart from a typed one.
- Safety still lives in prose (the Risk Assessment section). A structured risk record — ideation, intent, plan, means, protective factors, disposition — remains the better long-term owner and is not built here.
